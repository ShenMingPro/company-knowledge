## 项目经历

### 企业级知识库智能问答系统（RAG） ｜ 个人全栈项目 ｜ 2026.06 – 2026.09

**技术栈**：Python / FastAPI / LangChain / ChromaDB / BM25 / Rerank / Redis / MySQL / Vue3 / TypeScript / Docker

**项目简介**：面向企业多部门知识空间的权限化智能问答系统。支持 TXT、PDF、DOCX、XLSX 文档入库与结构化分块，提供混合检索问答、引用溯源、拒答兜底，以及员工/客服/管理员三角色的权限管理与量化评测闭环。

- **检索架构**：设计「向量召回 + BM25 关键词召回 → RRF 排名融合 → Rerank 精排」三级检索流水线，兼顾语义泛化与型号/数字等精确匹配场景，解决单一向量检索对深层文档细节召回不全的问题
- **量化评测**：自建 60 题三角色评测集，采用 LLM-as-Judge 三档评分体系，系统加权准确率 82.5%；通过错误归因定位「精排截断导致多要点覆盖不足」瓶颈并修复复测，形成评测驱动的迭代闭环
- **检索增强**：实现规则前置的多轮 Query 改写（仅含指代词的追问触发 LLM 改写，降低 Token 消耗）；按文档类型自适应分块（章节/问答对/条目）并继承元数据，保障引用可溯源；基于 Rerank 相关性分数实现可答性判断与标准拒答兜底
- **权限安全**：实现 JWT 认证（令牌仅含用户 ID，每请求回库校验角色与状态，杜绝权限变更后的残留越权）+ FastAPI 依赖注入的接口级 RBAC + 检索层知识空间过滤的三层纵深防御；基于 Redis 黑名单实现令牌登出即吊销；登录限流采用 IP + 账号双维度，密码校验防时序侧信道用户枚举
- **高并发支撑**：使用 Redis 实现热点数据缓存（含写失效策略）、滑动窗口限流（429 + Retry-After）与异步索引任务状态机（进度查询 + 归属校验）；按「安全控制 fail-closed、可用性功能 fail-soft」原则实现分级降级
- **工程化**：FastAPI 异步接口 + Vue3/TypeScript 前后端分离；Docker Compose 一键部署（含 Nginx 反向代理）；编写 SQLite → MySQL 迁移脚本；pytest 20 个用例覆盖鉴权、限流、缓存、任务全链路
